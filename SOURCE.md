# Source of the data example

- Provider: NOAA Global Drifter Program.
- Product: six-hourly quality-controlled, interpolated drifter data.
- Product page: https://erddap.aoml.noaa.gov/gdp/erddap/tabledap/drifter_6hour_qc.html
- Product identifier: https://doi.org/10.25921/7ntx-z961
- Data terms: Creative Commons Attribution 4.0, as recorded in `DATA_TERMS.txt`.

The example preserves a short excerpt of rows from a historical provider
response. The response has been shortened; its retained values, field names and
unit entries have not been altered. Null unit entries are preserved rather than
assigned inferred units. This excerpt is provided to illustrate the source
product's data format.

Data attribution: This example uses data collected and made freely available by
the NOAA Global Drifter Program (https://www.aoml.noaa.gov/phod/gdp/), accessed
through its public ERDDAP service.

Please retain the provider attribution and follow the accompanying data terms
when reusing the example.
